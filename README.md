# Python Programming Lab Assignments

**Course:** Python Programming (N-SECCS401P)  
**Institution:** S.B. Jain Institute of Technology, Management & Research, Nagpur  
**Department:** Computer Science & Engineering  
**Academic Year:** 2025-2026

## 📚 About This Repository

This repository contains all practical lab assignments completed during the Python Programming course. Each assignment demonstrates different Python programming concepts from basics to advanced topics.

## 📂 Contents

### **Practical 1: Basic Input/Output & Calculations**
- **Assignment 1:** Employee Salary Calculator - Calculate salary with allowances (DA, HRA, TA) and deductions (LIC)
- **Assignment 2:** Vendor Billing System - Store vendor details and generate annual purchase report

### **Practical 2: Conditional Statements**
- **Assignment 1:** Ohm's Law Calculator - Calculate current and classify it as Low/Normal/High
- **Assignment 2:** Steel Quality Grading System - Grade steel based on hardness, carbon content, and tensile strength

### **Practical 3: Loops & Patterns**
- **Assignment 1:** Number Patterns
- **Assignment 2:** Character and Symbol Patterns
- **Assignment 3:** Print Consecutive Numbers
- **Assignment 4:** Descending Star Pattern
- **Assignment 5:** Pyramid Star Pattern
- **Assignment 6:** Reverse Pyramid Pattern
- **Assignment 7:** Prime Number Finder


### **Practical 4: NumPy Operations**
- **Assignment 1:** Create 4×4 identity matrix and perform matrix operations
- **Assignment 2:** Matrix multiplication (5×3 with 3×2)

### **Practical 5: Tuple Operations**
- **Assignment 1:** Comprehensive tuple operations (count, print last, reverse, check item, remove first & last)
- **Assignment 2:** Shop pricing system using tuples (find total, cheapest, costliest, sorted prices)

### **Practical 6: String Manipulation**
- **Assignment 1:** String Statistics - Count vowels, consonants, spaces, and lowercase letters
- **Assignment 2:** Capitalize Lines - Convert multi-line input to uppercase

### **Practical 7: Functions**
- **Assignment 1:** Calculator - Menu-driven calculator with functions for basic operations
- **Assignment 2:** Bank Account System - Functions for balance, deposit, and withdrawal

### **Practical 8: File Handling**
- **Assignment 1:** Text File to Uppercase - Read file and create uppercase version
- **Assignment 2:** Copy Python Script Without Comments - Copy .py file excluding comments

### **Practical 9: Object-Oriented Programming**
- **Assignment 1:** Employee-Manager System - Inheritance with Employee and Manager classes
- **Assignment 2:** Library Management System - Classes for Book, Member, Library with menu interface

### **Practical 10: Pandas DataFrame Operations**
- **Assignment 1:** Books Analysis - Analyze books.csv with various operations
- **Assignment 2:** States Analysis - Create and analyze state information with population density

### **Practical 11: Data Visualization**
- **Assignment 1:** Cosmetic Sales Visualization - Line, Multi-line, Bar, and Pie charts
- **Assignment 2:** Recruitment Analysis - Visualize company recruitment data

### **Practical 12: Advanced Pandas**
- **Assignment 1:** Diamonds DataFrame Analysis - Statistical analysis on diamond data
- **Assignment 2:** Employee Excel Analysis - Read employee.xlsx and generate filtered reports

## 🚀 How to Run

1. Clone this repository
2. Install required libraries: `pip install numpy pandas matplotlib openpyxl`
3. Run any assignment: `python practical_1_assignment_1.py`

## 📦 Requirements

- Python 3.x
- NumPy
- Pandas
- Matplotlib
- openpyxl (for Excel files)
